# The Tech Academy - Basic C# Projects

This repository contains coding projects and exercises completed as part of The Tech Academy's Basic C# course. It serves as a portfolio of my coding work and will continue to be updated as I progress through the program.

## Skills Demonstrated

- **C# Fundamentals**: variables, data types, conditionals, loops, methods
- **Object-Oriented Programming**: classes, properties, constructors, encapsulation
- **Interfaces & Polymorphism**: defining and implementing custom interfaces, using interface types to reference objects
- **Operator Overloading**: overloading equality operators (`==`, `!=`) to compare custom objects
- **ASP.NET MVC**: building web applications following the Model-View-Controller pattern
- **Entity Framework (Code-First)**: designing models, generating databases from code, and querying data with EF6 and EF Core
- **Database Design**: connecting applications to SQL Server, SQLite, and SQL Server Compact databases
- **Debugging**: using Visual Studio's debugger (breakpoints, step-through) to trace and understand program execution
- **Version Control**: managing project history and collaboration using Git and GitHub

## Projects

| Project | Description | Skills |
|---|---|---|
| **Package Express** | Console app that calculates a shipping quote based on package weight and dimensions | Conditionals, console I/O |
| **Math Operations** | Console app demonstrating a class with a method that takes parameters by position and by name | Classes, methods, parameter passing |
| **IQuittable Interface** | Console app demonstrating a custom interface implemented by an Employee class, used polymorphically | Interfaces, polymorphism |
| **Employee Equality** | Console app demonstrating overloaded `==`/`!=` operators to compare Employee objects by ID | Operator overloading |
| **Car Insurance Quote App** | ASP.NET MVC web application with Entity Framework that calculates and stores insurance quotes based on user input, including an admin view of all quotes issued | ASP.NET MVC, Entity Framework, database design |
| **EF Code-First Demo** | Console app demonstrating Entity Framework's Code-First approach: defining a model, generating a database from code, and adding a record | Entity Framework Code-First |
